# 7.1.2 线搜索 Newton–CG 方法：用共轭梯度解牛顿方程

牛顿法每步要解 Hₖpₖ=−gₖ。当 Hessian 又大又稀疏时，直接分解不可行。线搜索 Newton–CG（截断牛顿法）用共轭梯度法近似求解这个系统：只需要 Hessian–向量乘积，不存储矩阵，并在残差足够小时提前停止。

## 为什么用 CG 解牛顿方程

共轭梯度法求解对称正定系统 Hp=−g，只依赖矩阵-向量乘积 Hd。若 H 由有限差分、自动微分或解析公式给出乘积算子，就可以完全避开 O(n²) 的内存与 O(n³) 的分解。CG 从 z₀=0、r₀=g、d₀=−r₀ 出发，第 i 步用 rᵢ 与共轭方向 dᵢ 更新 zᵢ₊₁、rᵢ₊₁、dᵢ₊₁。每一步恰好一次 Hessian–向量乘积。

## 什么时候停止内迭代

不把系统解到底。给定 forcing 项 ηₖ∈(0,1)，当残差范数满足

  ‖rᵢ‖ ≤ ηₖ‖gₖ‖

时停止，取当前 zᵢ 作为不精确牛顿步。ηₖ 越大，内迭代越少、外层收敛越慢；实用选择是 ηₖ=min(0.5, √‖gₖ‖)，它在离解较远时放宽、接近解时收紧。这正是 7.1.1 的 forcing 项：ηₖ→0 时外层超线性收敛。

## 负曲率：必须中断

CG 的推导假设 H 对称正定。若某步遇到 dᵢᵀH dᵢ ≤ 0，则沿该方向目标函数没有下界（负曲率），继续迭代无意义。线搜索方法的标准处理是：停止内迭代，若这是第 0 步（d₀=−g 就给不出正曲率）则直接取 pₖ=−gₖ 作为下降方向；否则用当前的 zᵢ。

## 二维可复现算例

取二次函数 f(x)=½xᵀHx−gᵀx，H=[[4,1],[1,3]]，−g=(−4,−6)，真解 p*=−H⁻¹g=(6/11,20/11)≈(0.5455,1.8182)。

- η=0.5：容差 0.5‖g‖≈3.61，第 1 次内迭代后残差约 1.44 已达标，返回 p≈(0.9455,1.4182)，gᵀp≈−12.29<0（下降）。
- η=0.01：容差约 0.072，1 步不够，第 2 步残差归零，返回精确解。

对不定矩阵 H=diag(1,−1)、g=(1,1)，初始方向 d₀=(−1,−1) 给出 d₀ᵀHd₀=0，程序按负曲率规则停止并返回 −g=(−1,−1)。

以上均为教学示意，用于区分两条停止规则，不是性能基准。

## 交互与代码

交互面板用滑块选择 forcing 项 η，实时显示内迭代次数、停止原因与方向是否下降。随附 Python 程序只依赖标准库，实现截断 CG、重现上述算例并断言停止规则。

```python
"""Truncated Newton-CG on a 2D quadratic, plus a negative-curvature stop guard."""
def matvec(M, v):
    return (M[0][0]*v[0] + M[0][1]*v[1], M[1][0]*v[0] + M[1][1]*v[1])

def dot(u, v):
    return u[0]*v[0] + u[1]*v[1]

def norm(v):
    return dot(v, v) ** 0.5

def newton_cg(H, g, eta, max_iter=10):
    """Approximately solve H p = -g; stop when ||r|| <= eta*||g|| or curvature <= 0."""
    z, r = (0.0, 0.0), (g[0], g[1])
    d, rr, tol = (-r[0], -r[1]), dot(r, r), eta * norm(g)
    for i in range(max_iter):
        Hd = matvec(H, d)
        curvature = dot(d, Hd)
        if 0.0 >= curvature:
            return (z if i > 0 else (-g[0], -g[1])), i, "negative curvature"
        alpha = rr / curvature
        z = (z[0] + alpha*d[0], z[1] + alpha*d[1])
        r = (r[0] + alpha*Hd[0], r[1] + alpha*Hd[1])
        if tol >= norm(r):
            return z, i + 1, "residual tolerance"
        beta = dot(r, r) / rr
        rr = dot(r, r)
        d = (-r[0] + beta*d[0], -r[1] + beta*d[1])
    return z, max_iter, "iteration cap"

def main():
    H, g = ((4.0, 1.0), (1.0, 3.0)), (-4.0, -6.0)
    loose = newton_cg(H, g, 0.5)
    tight = newton_cg(H, g, 0.01)
    indefinite = newton_cg(((1.0, 0.0), (0.0, -1.0)), (1.0, 1.0), 0.3)
    assert loose[1] == 1 and loose[2] == "residual tolerance"
    assert dot(g, loose[0]) < 0.0
    assert tight[1] == 2 and abs(tight[0][0] - 6.0/11.0) < 1e-12
    assert indefinite[2] == "negative curvature" and indefinite[0] == (-1.0, -1.0)
    print("eta=0.50 -> steps", loose[1], loose[2], "p", tuple(round(v, 4) for v in loose[0]), "g.p", round(dot(g, loose[0]), 3))
    print("eta=0.01 -> steps", tight[1], tight[2], "p", tuple(round(v, 4) for v in tight[0]))
    print("indefinite -> steps", indefinite[1], indefinite[2], "p", indefinite[0])

if __name__ == "__main__":
    main()
```
