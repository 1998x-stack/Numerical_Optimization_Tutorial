# 7.1.1 不精确牛顿法的局部收敛：forcing 项如何决定收敛阶

牛顿法每步求解 ∇²f(xₖ)pₖ = −∇f(xₖ)。当 Hessian 很大或结构稀疏时，精确求解这个线性系统代价过高，实用算法只在“足够精确”的前提下近似求解。本页给出不精确牛顿法的容差条件，以及 forcing 项 ηₖ 如何决定线性、超线性与二次收敛。

## 精确求解为什么太贵

设 f 二阶连续可微，g(x)=∇f(x)，H(x)=∇²f(x)。牛顿步 pᴺₖ = −H(xₖ)⁻¹g(xₖ) 需要解一个 n×n 线性系统。若 H 稠密，分解代价约 O(n³)，内存 O(n²)，这对大规模问题不可接受。于是把“解到精确”换成“解到相对残差足够小”：

  ‖H(xₖ)pₖ + g(xₖ)‖ ≤ ηₖ ‖g(xₖ)‖,  0 ≤ ηₖ ≤ η < 1.

其中 rₖ = H(xₖ)pₖ + g(xₖ) 是不精确牛顿步的残差，ηₖ 称为 forcing 项。ηₖ 是旋钮：越小越接近真实牛顿步，也越贵；越大越省内层迭代，但外层收敛变慢。

## forcing 项决定收敛阶（Theorem 7.1）

设 ∇²f 在解 x* 处 Hölder 连续、∇²f(x*) 非奇异，且 xₖ→x*。则：

- 若 ηₖ ≤ η < 1（常数上界），{xₖ} 线性收敛；
- 若 ηₖ → 0，{xₖ} 超线性收敛；
- 若 ηₖ = O(‖g(xₖ)‖)，{xₖ} 二次收敛。

直觉来自误差递推 Eₖ₊₁ ≈ ηₖEₖ + O(Eₖ²)。第一项是“没有解到底”留下的线性误差，第二项才是牛顿法本身的二次项。常数 η 让第一项主导 → 线性；让 ηₖ→0 抑制第一项 → 超线性；让 ηₖ 与 Eₖ 同阶，则第一项也是二阶小量 → 二次。

## 几何：容差带

一维时令 h=H(xₖ)、pᴺ=−g/h。条件 |h p + g| ≤ η|g| 等价于 |p − pᴺ| ≤ η|pᴺ|，也就是不精确步落在 pᴺ 周围、相对半宽为 η 的区间里，等价地 xₖ₊₁ 落在以 x* 为中心、半宽 η|pᴺ| 的区间内。

## 一维可复现算例

取 f(x)=x²/2+x³/6，g(x)=x+x²/2，h(x)=1+x，x*=0（h(0)=1 非奇异）。按下式构造满足容差条件的步：

  xₖ₊₁ = xₖ − (1−ηₖ) g(xₖ)/h(xₖ).

三种 forcing 项的误差收缩表现如下（数值由随附程序计算）：

- ηₖ=0.5（常数）：收缩比 0.556 → 0.503，趋于 0.5，线性。
- ηₖ=0.5^(k+1)（趋于零）：收缩比 0.335 → 0.0078，超线性。
- ηₖ=0.5|g(xₖ)|（O(‖g‖)）：eₖ₊₁/eₖ² ≈ 1，二次。

该一维问题与取值均为教学示意，用来区分三种收敛阶，不代表任何大规模实验的性能基准。

## 交互与代码

交互面板用滑块选择 forcing 项 η，并切换 forcing 计划（常数 / 趋于零 / 与梯度同阶），实时显示末步收缩比与判定出的收敛阶。随附 Python 程序只依赖标准库，重现上述三组误差序列并断言其收敛阶。

```python
"""Inexact Newton on f(x)=x^2/2+x^3/6: the forcing term sets the convergence order."""
def grad(x):
    return x + x * x / 2

def hess(x):
    return 1.0 + x

def inexact_newton(x0, eta, steps):
    """eta(k, g) returns the residual factor; the step satisfies h*p + g = eta*g."""
    x, errors = x0, []
    for k in range(steps):
        gk, hk = grad(x), hess(x)
        x += -(1.0 - eta(k, gk)) * gk / hk
        errors.append(abs(x))
    return errors

def ratios(errors):
    return [errors[i + 1] / errors[i] for i in range(len(errors) - 1) if errors[i] > 1e-16]

constant = inexact_newton(0.5, lambda k, gk: 0.5, 7)
vanishing = inexact_newton(0.5, lambda k, gk: 0.5 ** (k + 1), 7)
quadratic = inexact_newton(0.5, lambda k, gk: 0.5 * abs(gk), 6)

if __name__ == "__main__":
    assert 0.55 > ratios(constant)[-1] > 0.45
    assert 0.02 > ratios(vanishing)[-1]
    assert all(1.1 * quadratic[i] ** 2 >= quadratic[i + 1] for i in range(1, 5))
    assert 1e-15 > quadratic[-1]
    print("constant  eta=0.5        ratios", [round(r, 3) for r in ratios(constant)])
    print("vanishing eta=0.5^(k+1)  ratios", [round(r, 4) for r in ratios(vanishing)])
    print("quadratic eta=0.5|g|     ratios", [f"{r:.2e}" for r in ratios(quadratic)])
    print("quadratic e[k+1]/e[k]^2 ", [round(quadratic[i + 1] / quadratic[i] ** 2, 3) for i in range(1, 5)])
```

## 这一页的边界

本页只讨论局部收敛：结论都假设 xₖ 已经在 x* 的吸引域内、且 ∇²f(x*) 非奇异。它不说明从任意起点都能收敛，也不涉及如何安全地选择 inner solver 的停止标准——那些属于全局化与 Newton–CG 的内容（7.1.2–7.1.3）。此外，“ηₖ=O(‖gₖ‖) 带来二次收敛”是渐近结论，实际实现常用启发式 forcing 项以平衡代价与精度。
