# 6.4.1 BFGS 的全局收敛：Zoutendijk 条件与水平集假设

线搜索方法的全局收敛通常从 Zoutendijk 条件入手。对 BFGS，还需要额外假设水平集有界且梯度 Lipschitz。结论是弱的：只保证 lim inf ‖gₖ‖=0，即存在子列趋于驻点。

## 全局收敛问的是什么

“全局收敛”在这里不是“找到全局最优”，而是“从任意初始点出发不会卡住不动”。典型结果是 lim inf_{k→∞}‖gₖ‖=0：至少存在一个子列趋于驻点。这比 lim‖gₖ‖=0 弱得多，却是能在一般非凸函数上证明的最强形式。非凸函数上梯度下降也可能长期停留在平坦区域，BFGS 也不例外。

## Zoutendijk 条件回顾

对所有下降方向 pₖ，只要线搜索满足 Wolfe 条件，就有 Zoutendijk 条件：

  ∑_{k=0}^∞ (−gₖᵀpₖ/(‖gₖ‖‖pₖ‖))² ‖gₖ‖² < ∞.

括号里是 −cosθₖ（θₖ 为 pₖ 与 −gₖ 的夹角）。若能证明 cosθₖ 不趋于零，级数收敛就逼出 ‖gₖ‖→0。对最速下降法 pₖ=−gₖ、cosθₖ≡1，结论直接成立；对 BFGS 则要控制 Hₖ 的条件数。

## BFGS 的全局收敛定理

假设 f 在水平集 Ω={x:f(x)≤f(x₀)} 上二阶连续可微，∇f 满足 Lipschitz 条件，且线搜索为满足 Wolfe 条件的线搜索。在这些假设下，BFGS 满足

  lim inf_{k→∞} ‖gₖ‖ = 0.

证明骨架：把 Zoutendijk 条件与夹角 cosθₖ 的逆界联起来；若 lim inf‖gₖ‖≠0，则由 BFGS 的更新结构推出 ∑cos²θₖ‖gₖ‖² 发散，与 Zoutendijk 条件矛盾。这里的结构依赖 Bₖ 正定与 sₖᵀyₖ>0，二者由 Wolfe 线搜索保证。

要点：这是存在性结论，不保证所有聚点都是驻点，也不保证全局最小。对凸函数，子列极限点即全局最小；对非凸函数，它只说“不会无限卡在非驻点上”。

## 矩阵界与条件数

非凸函数的水平集可能很大，Bₖ 与 Hₖ 的条件数无上界。在凸函数且水平集凸的假设下才能控制条件数。因此定理里的“凸水平集”假设换来了 Hₖ 谱的界，不是装饰。

## 假设不可省略

线搜索只满足 Armijo 时 sₖᵀyₖ 可能为负、正定性失效；水平集无界或梯度不 Lipschitz 时条件数可能无限变坏，Zoutendijk 条件的下界丢失。“BFGS 全局收敛”必须带上条件：Wolfe 线搜索、凸水平集、Lipschitz 梯度。

## 交互与代码

页面交互面板拖动起点 x 坐标，显示 BFGS（H₀=I、精确线搜索）在这条 Rosenbrock 轨迹上的迭代数与末态 ‖g‖；各起点都会降到容差以下。随附 Python 程序从 4 个起点出发，断言都降到 ‖g‖<10⁻⁶。这是全局收敛的数值侧面，不是其证明。

```python
"""Run BFGS (exact line search) on Rosenbrock from several starts."""
import math

def f(p):
    return 100.0*(p[1]-p[0]**2)**2 + (1.0-p[0])**2

def grad(p):
    return (-400.0*p[0]*(p[1]-p[0]**2) - 2.0*(1.0-p[0]), 200.0*(p[1]-p[0]**2))

def exact_search(x, p):
    lo, hi = 0.0, 2.0
    gr = (math.sqrt(5.0)-1.0)/2.0
    c, d = hi-gr*(hi-lo), lo+gr*(hi-lo)
    fc, fd = f((x[0]+c*p[0], x[1]+c*p[1])), f((x[0]+d*p[0], x[1]+d*p[1]))
    for _ in range(80):
        if fc < fd:
            hi, d, fd = d, c, fc
            c = hi-gr*(hi-lo); fc = f((x[0]+c*p[0], x[1]+c*p[1]))
        else:
            lo, c, fc = c, d, fd
            d = lo+gr*(hi-lo); fd = f((x[0]+d*p[0], x[1]+d*p[1]))
    return 0.5*(lo+hi)

def bfgs(x0, tol=1e-6, maxit=200):
    n = 2; x = list(x0)
    H = [[1.0 if i == j else 0.0 for j in range(n)] for i in range(n)]
    for it in range(1, maxit+1):
        g = grad(x)
        if math.hypot(*g) < tol:
            return it-1, x, math.hypot(*g)
        Hg = [sum(H[i][j]*g[j] for j in range(n)) for i in range(n)]
        p = [-v for v in Hg]
        a = exact_search(x, p)
        xn = [x[i]+a*p[i] for i in range(n)]; gn = grad(xn)
        s = [xn[i]-x[i] for i in range(n)]; y = [gn[i]-g[i] for i in range(n)]
        sy = sum(s[i]*y[i] for i in range(n))
        if sy > 1e-12:
            rho = 1.0/sy
            Hy = [sum(H[i][j]*y[j] for j in range(n)) for i in range(n)]
            yHy = sum(y[i]*Hy[i] for i in range(n))
            H = [[H[i][j] - rho*(s[i]*Hy[j] + Hy[i]*s[j])
                  + rho*rho*yHy*s[i]*s[j] + rho*s[i]*s[j]
                  for j in range(n)] for i in range(n)]
        x = xn
    return maxit, x, math.hypot(*grad(x))

if __name__ == "__main__":
    for x0 in ((-1.2, 1.0), (0.0, 1.0), (2.0, 1.0), (-2.0, 1.0)):
        it, x, gn = bfgs(x0)
        assert gn < 1e-6
        print("start", x0, "->", it, "iters, |g| =", gn)
```
