6.4.1 BFGS 的全局收敛：Zoutendijk 条件与水平集假设

线搜索方法的全局收敛通常从 Zoutendijk 条件入手。对 BFGS，还需要额外假设水平集有界且梯度 Lipschitz。结论是弱的：只保证 lim inf ‖gₖ‖=0，即存在子列趋于驻点。

收敛定理假设剖析可复现实验

全局收敛问的是什么

“全局收敛”在这里不是“找到全局最优”，而是“从任意初始点出发不会卡住不动”。线搜索方法的典型结果是 lim infk→∞ ‖gₖ‖=0：至少存在一个子列趋于驻点。这比 lim ‖gₖ‖=0 弱得多，却是能在一般非凸函数上证明的最强形式。

为什么只能弱到这一步：非凸函数上梯度下降也可能长期停留在平坦区域；线搜索只能保证函数值持续下降，不能排除数值上极慢的漂移。BFGS 也不会例外——它的全局结论同样只是 lim inf。

Zoutendijk 条件回顾

对所有下降方向 pₖ，只要线搜索满足 Wolfe 条件，就有 Zoutendijk 条件：

∑k=0∞(−gk⊤pk‖gk‖‖pk‖)2‖gk‖2<∞.

括号里的量是 −cos θₖ，θₖ 是 pₖ 与 −gₖ 的夹角。若还能证明 cos θₖ 不趋于零（即方向不会无限接近与梯度垂直），那么左边就有正的下界与 ‖gₖ‖² 相乘，级数收敛就逼出 ‖gₖ‖→0。

对最速下降法，pₖ=−gₖ，cosθₖ≡1，结论直接成立。对 BFGS 则多一层困难：pₖ=−Hₖgₖ 的夹角依赖于 Hₖ 的条件数，而 Hₖ 本身在迭代中变化。要控制它，就需要对 Hₖ 与 Bₖ 给出一致的界。

BFGS 的全局收敛定理

原书给出的全局收敛结论需要额外的结构假设：f 在水平集 Ω={x:f(x)≤f(x₀)} 上二阶连续可微，∇f 满足 Lipschitz 条件，并且（利用线搜索保证）每次曲率条件成立。在这些假设下，BFGS 配合满足 Wolfe 条件的线搜索得到

lim infk→∞‖gk‖=0.

证明的骨架是把 Zoutendijk 条件与一个关于夹角 cos θₖ 的逆界联起来：若 lim inf‖gₖ‖≠0，则可由 BFGS 的更新结构推出 ∑cos²θₖ‖gₖ‖² 发散，与 Zoutendijk 条件矛盾。这里的“结构”依赖 Bₖ 的正定性与 sₖᵀyₖ>0，而这两者又由 Wolfe 线搜索保证。

要点：这是存在性结论。它不保证所有聚点都是驻点，也不保证收敛到全局最小。对凸函数，子列极限点也就是全局最小；对非凸函数，它只说“不会无限卡在非驻点上”。

矩阵界与条件数

非凸函数的水平集可能很大，Bₖ 与 Hₖ 的条件数也无从上界。原书指出：在凸函数且水平集凸的假设下，才能真正控制条件数，得到上述全局收敛。换句话说，定理里的“凸水平集”假设不是装饰，它换来了 Hₖ 谱的界。

实践含义：在非凸问题上，BFGS 的全局收敛没有普适保证，但它通常仍然工作得很好，且往往比最速下降快得多。这一经验事实与本节的存在性结果不矛盾：后者只是最低标准。

假设不可省略

去掉假设后的反例说明全局收敛不是免费的。线搜索只满足 Armijo 时，sₖᵀyₖ 可能为负，正定性失效，方向甚至可能不会下降；水平集无界或梯度不 Lipschitz 时，Bₖ 的条件数可能无限制变坏，Zoutendijk 条件的下界就丢失了。

因此“BFGS 全局收敛”这句话必须带上条件：Wolfe 线搜索、凸水平集、Lipschitz 梯度。把它当成无条件保证是过度解读。

lim inf 只要求存在子列趋于驻点，不要求整条序列都单调靠拢。

Python：从多个起点验证下降

程序只依赖标准库，用精确线搜索的 BFGS 从几个不同起点出发，断言每个都降到 ‖g‖<10⁻⁶。这是全局收敛结论的数值侧面，不是其证明。

"""Run BFGS (exact line search) on Rosenbrock from several starts."""
import math

def f(p):
    return 100.0*(p[1]-p[0]**2)**2 + (1.0-p[0])**2

def grad(p):
    return (-400.0*p[0]*(p[1]-p[0]**2) - 2.0*(1.0-p[0]), 200.0*(p[1]-p[0]**2))

def exact_search(x, p):
    lo, hi = 0.0, 2.0
    gr = (math.sqrt(5.0)-1.0)/2.0
    c, d = hi-gr*(hi-lo), lo+gr*(hi-lo)
    fc, fd = f((x[0]+c*p[0], x[1]+c*p[1])), f((x[0]+d*p[0], x[1]+d*p[1]))
    for _ in range(80):
        if fc < fd:
            hi, d, fd = d, c, fc
            c = hi-gr*(hi-lo); fc = f((x[0]+c*p[0], x[1]+c*p[1]))
        else:
            lo, c, fc = c, d, fd
            d = lo+gr*(hi-lo); fd = f((x[0]+d*p[0], x[1]+d*p[1]))
    return 0.5*(lo+hi)

def bfgs(x0, tol=1e-6, maxit=200):
    n = 2; x = list(x0)
    H = [[1.0 if i == j else 0.0 for j in range(n)] for i in range(n)]
    for it in range(1, maxit+1):
        g = grad(x)
        if math.hypot(*g) < tol:
            return it-1, x, math.hypot(*g)
        Hg = [sum(H[i][j]*g[j] for j in range(n)) for i in range(n)]
        p = [-v for v in Hg]
        a = exact_search(x, p)
        xn = [x[i]+a*p[i] for i in range(n)]; gn = grad(xn)
        s = [xn[i]-x[i] for i in range(n)]; y = [gn[i]-g[i] for i in range(n)]
        sy = sum(s[i]*y[i] for i in range(n))
        if sy > 1e-12:
            rho = 1.0/sy
            Hy = [sum(H[i][j]*y[j] for j in range(n)) for i in range(n)]
            yHy = sum(y[i]*Hy[i] for i in range(n))
            H = [[H[i][j] - rho*(s[i]*Hy[j] + Hy[i]*s[j])
                  + rho*rho*yHy*s[i]*s[j] + rho*s[i]*s[j]
                  for j in range(n)] for i in range(n)]
        x = xn
    return maxit, x, math.hypot(*grad(x))

if __name__ == "__main__":
    for x0 in ((-1.2, 1.0), (0.0, 1.0), (2.0, 1.0), (-2.0, 1.0)):
        it, x, gn = bfgs(x0)
        assert gn < 1e-6
        print("start", x0, "->", it, "iters, |g| =", gn)

程序只用二维 Rosenbrock 与精确线搜索；它不测试非凸多元问题，也不验证定理的假设条件，因此不能当作全局收敛定理的证明。

参考依据：Nocedal & Wright, Numerical Optimization, 2nd edition，Chapter 3, Section 3.2（Zoutendijk 条件）与 Chapter 6, Section 6.4（BFGS 全局收敛的假设与 lim inf 结论），pp. 152–154。教学图、数值例子及代码均独立构造。
