# 4.4 信赖域 Newton：从截断步到局部超线性收敛

信赖域远离最优点时限制过大的 Newton 步；在 Hessian 正定的局部极小点附近，Newton 步趋于零且模型越来越可信，球约束最终不再阻碍快速局部收敛。

## Newton 步与球约束的竞争

模型 mₖ(p)=f(xₖ)+gₖᵀp+½pᵀHₖp，Hₖ=∇²f(xₖ)，选择 ‖p‖≤Δₖ。若 Hₖ 正定，完整 Newton 步 pᴺₖ=−Hₖ⁻¹gₖ 是二次模型的无约束最优点。远离解时，它可能超出球；局部收敛后 pᴺₖ 趋于零。



$$
p_k^N=-[\nabla^2 f(x_k)]^{-1}\nabla f(x_k)
$$

## 模型的三阶偏差如何带来高接受率

当 Hessian 在严格局部最小点附近 Lipschitz 连续，真实目标与二次模型的差具有 O(‖p‖³) 的上界。合适的二次预测下降通常在 ‖p‖² 量级，因此 |ρₖ−1| 可控制在 O(‖p‖)。这解释了为何局部小步会具有高模型质量比。



![远处完整 Newton 步可能超出小半径信赖域而被截断；接近最优点时 Newton 步足够短，完全落在球内。](../assets/figures/trust-newton-local.svg)

*远处完整 Newton 步可能超出小半径信赖域而被截断；接近最优点时 Newton 步足够短，完全落在球内。*

## 超线性与二次速度的逻辑边界

若子问题近似步满足 ‖pₖ−pᴺₖ‖=o(‖pᴺₖ‖)，在定理的局部假设下可以获得超线性收敛。要直接继承 Newton 的二次收敛，还需要最终精确采用完整 Newton 步，并满足解处 Hessian 正定及局部 Lipschitz 条件。一个小 o 近似本身不推出二次收敛。



## 曲率随位置变化的可运行示例

取 f(x)=½x²+0.1x³+0.05x⁴，梯度 g=x+0.3x²+0.2x³，Hessian H=1+0.6x+0.6x²=0.6(x+0.5)²+0.85＞0。它有唯一最优点 x*=0。

从 x₀=0.8 且 Δ₀=0.3 开始，Newton 方向约 −0.58712，第一步会被截断为 −0.3。使用实际/预测下降比更新半径后，后续完整 Newton 步得以接受，并迅速接近零。

## 什么时候快速局部速度不能照搬

如果 Hₖ 奇异、不定，或模型近似与真实 Hessian 差距较大，Newton 方向可能并非二次模型的极小方向。若外层算法错误地将 Δ 固定为非常小，也可能反复截断完整 Newton 步。应记录梯度范数、ρ、Δ 与是否放行完整 Newton 步。

## Python：可运行示例

```python
"""Trust-region Newton iteration for a strictly convex nonquadratic example."""
def f(x): return .5*x*x+.1*x**3+.05*x**4
def g(x): return x+.3*x*x+.2*x**3
def H(x): return 1+.6*x+.6*x*x
def run(x=.8,delta=.3):
    history=[]
    for i in range(20):
        grad,curv=g(x),H(x)
        if abs(grad)<1e-13: break
        newton=-grad/curv
        p=max(-delta,min(delta,newton))
        prediction=-grad*p-.5*curv*p*p
        if prediction<=0: raise RuntimeError("nonpositive decrease")
        rho=(f(x)-f(x+p))/prediction
        history.append((x,delta,p,newton,rho))
        if rho>=.1: x+=p
        if rho<.25: delta*=.25
        elif rho>.75 and abs(abs(p)-delta)<1e-12:
            delta=min(5.,2*delta)
    return x,history
if __name__=="__main__":
    x,history=run()
    print("final",x,"iterations",len(history))
    for row in history: print(row)
    assert abs(x)<1e-10
    assert history[0][2]==-.3
    assert abs(history[0][3])>.3
    assert any(abs(p-n)<1e-12 for _,_,p,n,_ in history[1:])
    assert abs(history[-1][-1]-1)<1e-5
```

## 理论边界与出处

二次收敛需要最终采用完整 Newton 步与 Hessian 正则性；仅渐近接近 Newton 步通常提供超线性结论。
