3.7 线搜索四个可独立推导的练习与解答

能够写出 Wolfe 不等式，并不意味着理解何时接受步长、何时需要修正方向。四个原创小问题从曲率区间、二次精确步长、Armijo 回溯和 Hessian 负曲率逐步检查这些区别。

概念与推导反例与边界运行验证

练习一：强 Wolfe 到底允许哪些步长

问题：定义 φ(α)=(α−2)²，起点 α=0，取 c₁=10⁻⁴、c₂=0.1。求使曲率条件成立的全部正 α，并确认其中 α=2 满足充分下降。

解析：φ′(α)=2(α−2)，φ′(0)=−4。强 Wolfe 曲率要求 |2(α−2)|≤0.4，所以 1.8≤α≤2.2。在 α=2 时，φ=0，而 Armijo 上界为 4−0.0008，故接受；“曲率允许区间”仍需和 Armijo 允许集合求交。

1.8≤α≤2.2

练习二：二次函数上的精确线搜索

问题：f(x,y)=½(4x²+y²)，从 (1,1) 沿负梯度 p=−g 走一步。求最佳 α 并验证该步使函数值严格下降。

解析：g=(4,1)，B=diag(4,1)。对一维模型求导等于零，得到 α*=gᵀg/(gᵀBg)=17/65≈0.261538；新点为 (−3/65,48/65)，函数值小于起点 2.5。该 α 是此方向上的精确极小步，不等于全局算法从任意点一步到达最优。

练习三：为什么要进行三次 Armijo 试探

问题：使用 φ(α)=(α−2)²、c=10⁻⁴、初始步长 α₀=8 和缩短比例 ρ=0.5。按照 Armijo 条件逐次判断是否接受。

解析：在 α=8 时 φ=36，远高于上界约 3.9968；在 α=4 时 φ=4，而上界约 3.9984，仍失败；在 α=2 时 φ=0，小于上界约 3.9992，通过。总计三次试探。回溯只验证充分下降，不自动保证 Wolfe 曲率条件。

练习四：Newton 方向可能指向上坡

问题：给出 g=(1,2)、H=diag(2,−1)。解 H p=−g，并判断 p 是不是下降方向；再取 B=H+2I 重新计算。

解析：普通 Newton 步 pᴺ=(−0.5,2)，梯度内积 gᵀpᴺ=−0.5+4=3.5＞0，因此不是下降方向。B=diag(4,1) 正定，修正方向 p=(−0.25,−2)，梯度内积 −4.25＜0。正定修正只恢复局部下降性，步长仍需要检查。

综合检查：不要把不同结论混成一个

练习一决定可接受的步长集合；练习二仅在一条线上的精确最小化；练习三展示了 Armijo 几何缩短；练习四则先修复方向本身。四个命题互不替代。

完成后建议自己重算每一项函数值、梯度和方向导数，再运行下方 Python 断言；若两者不一致，应先核对符号与系数，而不是调整代码让断言通过。

程序对应上面的四道原创练习。它检验公式和算例，不充当通用线搜索或 Newton 迭代库。

"""Four original exercises on Wolfe, exact steps, Armijo and Newton curvature."""
def strong_wolfe(alpha, c1=1e-4, c2=0.1):
    phi = (alpha - 2.0)**2
    return (phi <= 4.0 - 4*c1*alpha
            and abs(2*(alpha-2)) <= 4*c2)

def exact_step():
    alpha = 17.0/65.0
    x = (1.0-4*alpha, 1.0-alpha)
    value = 0.5*(4*x[0]**2+x[1]**2)
    return alpha, x, value

def armijo_trials():
    trials = []
    for alpha in (8.0, 4.0, 2.0):
        accepted = (alpha-2)**2 <= 4-4e-4*alpha
        trials.append((alpha, accepted))
        if accepted:
            break
    return trials

def newton_slopes():
    return 1*(-0.5)+2*2, 1*(-0.25)+2*(-2)

if __name__ == "__main__":
    assert strong_wolfe(2.0)
    assert not strong_wolfe(0.5)
    a, x, value = exact_step()
    print("exact:", a, x, value)
    assert abs(a-17/65) < 1e-12 and value < 2.5
    assert armijo_trials() == [(8.0,False),(4.0,False),(2.0,True)]
    assert newton_slopes() == (3.5,-4.25)
