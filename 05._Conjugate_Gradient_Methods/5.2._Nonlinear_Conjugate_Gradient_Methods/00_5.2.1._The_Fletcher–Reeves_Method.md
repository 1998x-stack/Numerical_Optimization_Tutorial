# 5.2.1 Fletcher–Reeves 方法：用梯度范数之比生成共轭方向

线性共轭梯度（5.1 节）解决固定线性方程组 Qx=b，其中 Q 对称正定，所有方向关于同一个 Q 共轭。一般非线性问题要极小化光滑函数 f(x)，不存在全局的 Q，也就没有固定的共轭内积。把线性 CG 里的残差换成梯度 g_k=∇f(x_k)，把固定步长换成线搜索，形式上得到同一个递推 p_k=−g_k+β_k p_{k−1}；区别只剩 β_k 要由非线性信息决定。

## Fletcher–Reeves 递归

Fletcher 与 Reeves（1964）取相邻梯度平方范数之比：

    p_k = −g_k + β_k p_{k−1},    β_k = (g_kᵀg_k) / (g_{k−1}ᵀg_{k−1}),    p_0 = −g_0.

算法 5.4（见 Nocedal & Wright §5.2.1）：给定 x_0，令 p_0=−g_0；对 k=0,1,… 用线搜索求步长 α_k，令 x_{k+1}=x_k+α_k p_k；若 ‖g_{k+1}‖ 足够小则停；否则算 β_{k+1} 与 p_{k+1}。注意 g_k 在分子、g_{k−1} 在分母，索引容易写反。

## 第一步退化为最速下降

初始方向 p_0=−g_0 就是最速下降方向，之后每一步借 β_k 引入前一步的曲率信息。精确线搜索给出 g_kᵀp_{k−1}=0，于是 g_kᵀp_k=−‖g_k‖²<0：FR 方向在精确线搜索下自动是下降方向，这一性质来自线搜索而非额外假设。

## 二维可复现算例

沿用 5.1.1 的同一正定二次问题：Q=[[3,1],[1,3]]，b=(5,7)，∇f(x)=Qx−b，x*=(1,2)。起点 x_0=(0,0) 给出 g_0=(−5,−7)，p_0=(5,7)。第一次线搜索：p_0ᵀQp_0=292，g_0ᵀp_0=−74，故 α_0=37/146，x_1=(185/146,259/146)，g_1=(42/73,−30/73)，β_1=(42²+30²)/(73²·74)=36/5329。第二次线搜索给 α_1=73/148，x_2=(1,2)=x*，β_2=0 终止。数值由下方 Python 用精确分数断言核验。

## 与线性 CG 的关系与边界

在正定二次问题上，精确线搜索的 FR 与线性共轭梯度取相同方向、相同步长，因而继承 n 步终止与 Krylov 最优性。对一般非线性函数则没有这层保证：β_k 可能过大，使方向偏离甚至不再下降，从而停滞，这正是 5.2.2 变体与 5.2.3 重启要处理的问题。本页程序只处理一个固定二维二次问题，不是通用求解器。

## Python 示例

```python
"""Fletcher-Reeves nonlinear conjugate gradient on a 2x2 quadratic."""
from fractions import Fraction

Q = ((3, 1), (1, 3))
b = (5, 7)

def matvec(M, v):
    return (M[0][0]*v[0] + M[0][1]*v[1], M[1][0]*v[0] + M[1][1]*v[1])

def dot(u, v):
    return u[0]*v[0] + u[1]*v[1]

def gradient(x):
    q = matvec(Q, x)
    return (q[0] - b[0], q[1] - b[1])

def fletcher_reeves(x0, max_iter=10):
    x, g = x0, gradient(x0)
    p = (-g[0], -g[1])
    trace = []
    for k in range(max_iter):
        alpha = -dot(g, p) / dot(p, matvec(Q, p))
        x = (x[0] + alpha*p[0], x[1] + alpha*p[1])
        g_next = gradient(x)
        beta = dot(g_next, g_next) / dot(g, g)
        trace.append((k, alpha, beta, x))
        if dot(g_next, g_next) < Fraction(1, 10**12):
            break
        p = (-g_next[0] + beta*p[0], -g_next[1] + beta*p[1])
        g = g_next
    return x, trace

if __name__ == "__main__":
    x_star, trace = fletcher_reeves((Fraction(0), Fraction(0)))
    assert trace[0][1] == Fraction(37, 146)
    assert trace[0][2] == Fraction(36, 5329)
    assert trace[1][1] == Fraction(73, 148)
    assert trace[1][2] == 0
    assert x_star == (Fraction(1), Fraction(2))
    print("x* =", x_star, "beta =", [str(t[2]) for t in trace])
```
