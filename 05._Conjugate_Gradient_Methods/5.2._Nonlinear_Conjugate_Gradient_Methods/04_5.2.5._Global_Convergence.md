# 5.2.5 全局收敛：Zoutendijk 条件下的 β 有界性

3.2 节的 Zoutendijk 条件指出：若每个搜索方向下降、步长满足 Wolfe 条件、目标在水平集上有下界且梯度 Lipschitz，则

    Σ cos²θ_k ‖g_k‖² < ∞  ⇒  lim ‖g_k‖ = 0,

其中 cosθ_k=−g_kᵀp_k/(‖g_k‖‖p_k‖) 是下降角。条件形状是“级数收敛⇒梯度趋零”，难点在于证明级数收敛。

## 为何需要 β 有界

对非线性 CG，还需保证 cosθ_k 与 ‖g_k‖ 配合使级数收敛。FR 的方向导数为 g_kᵀp_k=−‖g_k‖²+β_k g_kᵀp_{k−1}；若 β_k 无界，p_k 被上一步方向主导，cosθ_k 可能趋于 0，级数发散，Zoutendijk 什么也不给。所以证明分两步：先证 β_k 有界，再代入 Zoutendijk。

## FR 的收敛结论

Al-Baali（1985）证明：f 在水平集上有下界、∇f Lipschitz 连续，线搜索满足强 Wolfe 且 σ<1/2，则 Fletcher–Reeves 全局收敛，liminf‖g_k‖=0。结论是最小极限为零，不保证每段轨迹单调。

## PR 的反例与 PR+

Powell（1984）构造三维函数使 PR 即使精确线搜索也不收敛：迭代绕圈、‖g_k‖ 有正下界。修正办法是 PR+（β^{PR} 取非负部分）；Gilbert 与 Nocedal（1992）证明 PR+ 在强 Wolfe 线搜索下全局收敛，等价于坏方向上重启。

## 边界与证据

所有结论都带假设：目标光滑、水平集有界、梯度 Lipschitz、线搜索满足强 Wolfe 且 σ<1/2。它们只保证收敛到驻点，不区分极小与鞍点，也不给收敛速度。本页不重述证明，只给出条件、结论与边界。

## Python 示例

```python
"""Zoutendijk implication: the angle bound decides whether the sum stays finite."""
import math
from fractions import Fraction

def series(angle2, grad2, n):
    return sum(angle2(k) * grad2(k) for k in range(1, n + 1))

if __name__ == "__main__":
    n = 1000
    vanish = series(lambda k: Fraction(1, 4), lambda k: Fraction(9, 10)**(2*k), n)
    limit = Fraction(81, 76)
    assert vanish < limit
    flat = series(lambda k: Fraction(1, 4), lambda k: Fraction(1), n)
    assert flat == Fraction(n, 4)
    slow = series(lambda k: Fraction(1, k), lambda k: Fraction(1), n)
    assert math.log(n + 1) < float(slow) < 1 + math.log(n)
    print("vanishing gradient sum", round(float(vanish), 4), "< limit", float(limit))
    print("flat gradient sum", int(flat), "| slowly-vanishing angle sum", round(float(slow), 4))
```
