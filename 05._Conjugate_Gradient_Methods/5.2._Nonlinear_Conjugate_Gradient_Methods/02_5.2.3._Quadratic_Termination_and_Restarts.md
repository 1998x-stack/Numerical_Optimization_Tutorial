# 5.2.3 二次终止与重启：何时丢弃旧方向

正定二次目标上，精确线搜索的共轭梯度法第 n 步给出 x*；这一结论依赖 g_k 的一系列正交关系，而它们源于 Q 的常数性。一般目标的 Hessian 随 x 变化，二次模型只在局部成立。迭代 n 步后累积方向不再关于局部曲率共轭，继续沿用可能使 p_k=−g_k+β_k p_{k−1} 不再是下降方向。

## 每 n+1 步定期重启

最简单的处理是周期性重启：每 n+1 次迭代把 β 置零一次，即令 p_k=−g_k。重启点退化为最速下降方向，之后重新累积共轭信息。它保证至少每 n+1 步有一次严格下降方向，代价是丢弃可能仍有效的历史信息。

## Powell 重启判据

用相邻梯度的正交程度判断共轭性是否被破坏，当

    |g_kᵀ g_{k−1}| / ‖g_k‖² ≥ ν,   ν = 0.1

时重启。在二次问题、精确线搜索下有 g_kᵀg_{k−1}=0，比值应为零；比值变大正是非二次干扰的信号。

## 二维算例

沿用同一二次问题。第一步精确，第二步取 c=3/5，得 g_1=(42/73,−30/73)，g_2=(84/365,−60/365)。此时 g_2ᵀg_1=5328/26645，‖g_2‖²=10656/133225，相除得 5/2=2.5，远大于 ν=0.1，故触发重启、β_2 置零。对照 c=1 的精确步 g_2=0，无需重启。数值由下方 Python 用精确分数断言核验。

## 重启的取舍与边界

定期重启简单但可能过频，Powell 判据更省迭代但每步多一次内积判断。两者都不能保证一般非凸问题收敛到全局最优，只能保证下降与局部收敛。重启只处理“方向变坏”，不改变线搜索；实际代码需把它与满足 Wolfe 条件的线搜索配合使用。本页程序只在一个固定二维二次问题上核对判据数值，不是通用求解器。

## Python 示例

```python
"""Fletcher-Reeves with the Powell restart test on a 2x2 quadratic."""
from fractions import Fraction
Q = ((3, 1), (1, 3))
b = (5, 7)

def matvec(M, v):
    return (M[0][0]*v[0] + M[0][1]*v[1], M[1][0]*v[0] + M[1][1]*v[1])

def dot(u, v):
    return u[0]*v[0] + u[1]*v[1]

def gradient(x):
    q = matvec(Q, x)
    return (q[0] - b[0], q[1] - b[1])

def substep(x, p, c):
    alpha = -dot(gradient(x), p) / dot(p, matvec(Q, p))
    return (x[0] + c*alpha*p[0], x[1] + c*alpha*p[1])

def powell_ratio(g_prev, g_now):
    return abs(dot(g_now, g_prev)) / dot(g_now, g_now)

if __name__ == "__main__":
    x = (Fraction(0), Fraction(0))
    g0 = gradient(x)
    p0 = (-g0[0], -g0[1])
    x1 = substep(x, p0, Fraction(1))
    g1 = gradient(x1)
    fr1 = dot(g1, g1) / dot(g0, g0)
    p1 = (-g1[0] + fr1*p0[0], -g1[1] + fr1*p0[1])
    x_exact = substep(x1, p1, Fraction(1))
    assert gradient(x_exact) == (Fraction(0), Fraction(0))
    x2 = substep(x1, p1, Fraction(3, 5))
    g2 = gradient(x2)
    ratio = powell_ratio(g1, g2)
    assert ratio == Fraction(5, 2)
    restart = ratio >= Fraction(1, 10)
    assert dot(g2, (-g2[0], -g2[1])) < 0
    print("exact step: g =", gradient(x_exact), "| powell ratio =", ratio, "restart:", restart)
```
