# 5.2.4 Fletcher–Reeves 方法的行为：下降角与停滞

FR 的方向是 p_k=−g_k+β_k p_{k−1}，其中 β_k=‖g_k‖²/‖g_{k−1}‖²≥0。沿 p_k 的方向导数为 g_kᵀp_k=−‖g_k‖²+β_k g_kᵀp_{k−1}。只有 g_kᵀp_{k−1}=0（精确线搜索）时它才等于 −‖g_k‖²；线搜索不精确时第二项为正就可能让 p_k 变成上升方向。

## 下降角 θ

定义 p_k 与 −g_k 的夹角 θ_k，满足

    cos θ_k = −g_kᵀ p_k / (‖g_k‖ ‖p_k‖).

θ_k 越小越接近最速下降，越大则同样的步长下降越少。Zoutendijk 条件只要求 Σ cos²θ_k ‖g_k‖² 收敛，对 cosθ_k 的下界不作要求，因此 FR 允许个别迭代出现极小甚至负的 cosθ_k。

## 停滞的机制

当 β_k 接近 1，p_k≈p_{k−1}，连续两步几乎同向，搜索退化为沿同一直线的反复微调；若同时 ‖g_k‖ 变小而 ‖p_k‖ 不小，cosθ_k 就很小。这种方向几乎与梯度正交的“贴谷运行”称为停滞（jamming）。

## 玩具算例

取山谷型函数 f(x)=(x_1−1)²+5(x_2−x_1²)²，起点 (−1.2,1)，配合 Armijo 回溯线搜索。该低维玩具上 FR 用 52 步把 ‖g‖ 降到 1e-6 以下，但在第 10 步出现 cosθ=−0.05，方向已成上升方向。这组数字只说明机制，不代表一般问题的步数或性能排序。

## 变体与边界

缓解办法：换用可取负值的系数（PR/PR+，5.2.2）、按 Powell 判据或定期重启（5.2.3）、或改用满足强 Wolfe 条件的线搜索。FR 的优点是理论完整、每步廉价，缺点是缺乏自适应丢弃机制。本页算例只是二维玩具函数，不能当作基准；全局收敛条件见 5.2.5。

## Python 示例

```python
"""Fletcher-Reeves on a Rosenbrock-like valley with Armijo backtracking."""
import math

def f(p):
    return (p[0]-1)**2 + 5*(p[1]-p[0]**2)**2

def grad(p):
    x, y = p
    return [2*(x-1) - 20*x*(y-x*x), 10*(y-x*x)]

def run(x0, tol=1e-6, cap=500):
    x, g = list(x0), grad(x0)
    p = [-g[0], -g[1]]
    angles = []
    for _ in range(cap):
        if math.hypot(*g) < tol:
            break
        slope = g[0]*p[0] + g[1]*p[1]
        a = 1.0
        for _ in range(40):
            if f([x[0]+a*p[0], x[1]+a*p[1]]) <= f(x) + 1e-4*a*slope:
                break
            a *= 0.5
        x = [x[0]+a*p[0], x[1]+a*p[1]]
        gn = grad(x)
        beta = (gn[0]**2 + gn[1]**2) / (g[0]**2 + g[1]**2)
        p = [-gn[0] + beta*p[0], -gn[1] + beta*p[1]]
        cos = -(gn[0]*p[0] + gn[1]*p[1]) / (math.hypot(*gn)*math.hypot(*p))
        angles.append(cos)
        g = gn
    return x, math.hypot(*g), angles

if __name__ == "__main__":
    x, norm, angles = run((-1.2, 1.0))
    assert norm < 1e-6
    assert min(angles) < 0.0
    print("final", [round(v, 6) for v in x],
          "| min descent angle cos =", round(min(angles), 6),
          "| steps =", len(angles))
```
