# 5.2.2 Polak–Ribière 方法与变体：β 公式的分歧

Fletcher–Reeves 的 β_k=‖g_k‖²/‖g_{k−1}‖² 只比较相邻梯度的长度，忽略了方向变化。迭代进入曲率剧变区域时梯度可能几乎反转，而 FR 仍给出较大的正 β，把旧方向强行保留，使新方向变差甚至停滞。更自然的做法是让 β 度量“梯度改变了多少”。

## Polak–Ribière 系数

记 y_k=g_k−g_{k−1}，Polak–Ribière 取

    β_k^PR = g_kᵀ y_k / ‖g_{k−1}‖²,    y_k = g_k − g_{k−1}.

方向仍为 p_k=−g_k+β_k^PR p_{k−1}。展开分子得 g_kᵀ(g_k−g_{k−1})=‖g_k‖²−g_kᵀg_{k−1}：当相邻梯度正交时它等于 ‖g_k‖²，β^PR 退化为 β^FR；当梯度方向逆转、g_kᵀg_{k−1} 较大时分子可为负，β^PR 变负。

## Hestenes–Stiefel 与 PR+

Hestenes–Stiefel 把分母换成 y_k 与上一步方向的内积：β_k^HS=g_kᵀy_k/p_{k−1}ᵀy_k。它对分母敏感，不精确时往往给出更大的负值。常用修正 PR+ 取 β_k^{PR+}=max(0, β_k^{PR})：当 β^{PR}<0 时退回最速下降方向 p_k=−g_k。

## 精确线搜索下的等价

设上一段沿 p_{k−1} 精确搜索，且二次目标满足 g_kᵀg_{k−1}=0。精确线搜索给 g_kᵀp_{k−1}=0；又 p_{k−1}ᵀy_k=α_{k−1}p_{k−1}ᵀQp_{k−1}，而 α_{k−1}p_{k−1}ᵀQp_{k−1}=−g_{k−1}ᵀp_{k−1}=‖g_{k−1}‖²。于是 β^{HS} 的分母=‖g_{k−1}‖²，分子=‖g_k‖²，故 β^{HS}=β^{PR}=β^{FR}。

## 不精确线搜索下的分歧

把第二步改成只走精确步长的 c 倍，正交关系失效。以 5.2.1 的同一二次问题为例：第一步精确，第二步取 c=3/5，得到 x_2=(404/365, 697/365)，g_2=(84/365, −12/73)。此时 β^{FR}=4/25=0.16，β^{PR}=−6/25=−0.24，β^{HS}=−2/5=−0.40：FR 仍为正，PR 与 HS 已为负，而 PR+ 截断为 0。这些数值由下方 Python 用精确分数断言核验，属于教学算例。

## Python 示例

```python
"""Polak-Ribiere, Hestenes-Stiefel and Fletcher-Reeves beta on a 2x2 quadratic."""
from fractions import Fraction
Q = ((3, 1), (1, 3))
b = (5, 7)

def matvec(M, v):
    return (M[0][0]*v[0] + M[0][1]*v[1], M[1][0]*v[0] + M[1][1]*v[1])

def dot(u, v):
    return u[0]*v[0] + u[1]*v[1]

def gradient(x):
    q = matvec(Q, x)
    return (q[0] - b[0], q[1] - b[1])

def substep(x, p, c):
    alpha = -dot(gradient(x), p) / dot(p, matvec(Q, p))
    return (x[0] + c*alpha*p[0], x[1] + c*alpha*p[1])

def betas(g_prev, g_now, p_prev):
    y = (g_now[0] - g_prev[0], g_now[1] - g_prev[1])
    num = dot(g_now, y)
    return (dot(g_now, g_now) / dot(g_prev, g_prev),
            num / dot(g_prev, g_prev),
            num / dot(p_prev, y))

if __name__ == "__main__":
    x = (Fraction(0), Fraction(0))
    g0 = gradient(x)
    p0 = (-g0[0], -g0[1])
    x1 = substep(x, p0, Fraction(1))
    g1 = gradient(x1)
    fr1 = dot(g1, g1) / dot(g0, g0)
    p1 = (-g1[0] + fr1*p0[0], -g1[1] + fr1*p0[1])
    x2 = substep(x1, p1, Fraction(3, 5))
    fr, pr, hs = betas(g1, gradient(x2), p1)
    assert (fr, pr, hs) == (Fraction(4, 25), Fraction(-6, 25), Fraction(-2, 5))
    exact = betas(g1, gradient(substep(x1, p1, Fraction(1))), p1)
    assert exact == (Fraction(0), Fraction(0), Fraction(0))
    print("inexact c=3/5 -> FR, PR, HS =", fr, pr, hs, "| PR+ =", max(Fraction(0), pr))
```
